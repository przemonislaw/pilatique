# Pilatique — zasady CMS

## CMS obsługuje tylko

- Posty
- Strony
- Home settings
- Carousel max 3 zdjęcia

## Posts

Admin może:
- listować
- tworzyć
- edytować
- usuwać

## Pages

Admin może edytować tylko:
- `o-nas`
- `oferta-dla-firm/organizacja-jednostkowych-eventow`
- `oferta-dla-firm/core-and-glow`
- `oferta-dla-firm/stars-and-stretches`
- `oferta-dla-firm/organizacja-wyjazdow-integracyjnych`
- `dlaczego-warto/korzysci-dla-kregoslupa`
- `dlaczego-warto/poprawa-postury`

## Home settings

Admin może edytować:
- hero_title
- hero_subtitle
- cta_text
- cta_href
- carousel_images

## Zakazy

Nie dodawać:
- podglądu draft workflow
- moderatorów/editorów
- komentarzy
- analytics
- innych paneli
