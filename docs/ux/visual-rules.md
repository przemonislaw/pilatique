# Pilatique — visual rules

## Styl

- premium
- spokojny
- kobiecy, ale nie cukierkowy
- ciemne tła
- ciepłe beże / brązy / neutralne akcenty

## Layout

- desktop: lewy sidebar + prawa część contentu
- mobile: topbar + drawer
- jedna główna akcja CTA
- brak przeładowania elementami

## Typografia

- elegancka
- dużo oddechu
- wyraźna hierarchia
- bez agresywnych rozmiarów i ozdobników

## Animacje

- subtelne
- bez ciężkich efektów
- zero przesadnego motion

## UX

- prostota > ozdobność
- spacing > dekoracje
- czytelność > efekciarstwo
- każda sekcja ma jasny cel
