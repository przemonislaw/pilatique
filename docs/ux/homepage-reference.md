# Homepage reference

## Cel homepage

Homepage ma budować wrażenie:
- premium
- wyciszenia
- jakości butikowej
- świadomego ruchu i doświadczenia

## Elementy

- sidebar z logo
- nieklikalne nagłówki sekcji
- klikalne podstrony leaf
- hero z tłem carousel
- title
- subtitle
- jedno CTA

## Czego nie dodawać

- wielu kart
- rozbudowanych sekcji sprzedażowych
- sliderów z tekstami
- testimoniali bez wyraźnej potrzeby
- rozpraszających ikonografii
